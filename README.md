# CodeAlpha_Task2

This project is part of my CodeAlpha internship tasks.

## Task

The main aim of this task is to analyze a student performance dataset and create meaningful visualizations from the data.

## Dataset

The project uses the `xAPI-Edu-Data.csv` dataset, which contains information about students such as:

- Gender
- Nationality
- Raised hands
- Visited resources
- Absence days
- Student performance

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / VS Code

## Work Done

In this task, I performed:

- Loading the dataset
- Checking the structure of the data
- Checking missing values
- Removing duplicate records
- Exploring different variables
- Creating bar charts
- Creating histograms
- Creating box plots
- Creating scatter plots
- Creating a correlation heatmap
- Comparing student performance with different factors
- Finding useful patterns and insights

## Visualizations

The project includes visualizations for:

1. Student distribution by gender
2. Student distribution by nationality
3. Student performance distribution
4. Distribution of raised hands
5. Distribution of visited resources
6. Raised hands by performance
7. Raised hands vs visited resources
8. Raised hands vs absence days
9. Correlation between numerical variables
10. Average raised hands by performance
11. Average visited resources by performance
